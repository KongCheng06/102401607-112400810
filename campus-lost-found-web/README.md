# 校园失物招领 Web 

这是一个面向校园场景的失物招领交互原型，支持浏览、搜索、发布、拍照识物、智能匹配、联系失主/拾获者、标记完成和发送感谢信等流程。

项目不需要安装依赖或执行打包，适合课程演示、功能走查和测试练习。为避免测试时反复发布产生的无效数据长期残留，本原型不做数据持久化。

## 获取项目与运行

### 方式一：克隆后直接体验

先将远程仓库下载到电脑，再切换到本项目所在的子目录：

```bash
git clone https://github.com/KongCheng06/102401607-112400810.git
cd 102401607-112400810/campus-lost-found-web
```

找到该目录中的 `index.html`，选择 Chrome 或 Edge 打开。

这种方式不涉及 Node.js、数据库或包管理器。由于 OCR 和图片特征模型通过网络加载，体验识图功能时请保持联网。

### 方式二：通过静态服务访问

若直接打开 HTML 时出现资源无法加载或浏览器安全限制，可在 `campus-lost-found-web` 目录中执行：

```bash
python -m http.server 8000
```

服务启动后，在浏览器输入 [http://localhost:8000](http://localhost:8000)。该方式需要电脑已安装 Python 3，适合进行识图或兼容性测试。

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 失物/招领浏览 | 切换全部、寻物、招领和悬赏信息 |
| 文字搜索 | 按物品名称、分类、地点和描述搜索 |
| 拍照搜物 | 结合图片向量相似度和 OCR 关键词排序 |
| 发布信息 | 发布寻物或招领，可上传图片和设置悬赏 |
| 智能匹配 | 综合图片、类别、地点、时间和关键词生成匹配度 |
| 详情与联系 | 查看物品特征、发布人和匹配依据，进入站内聊天 |
| 完成与致谢 | 标记已找到/已归还，写感谢信并记录爱心积分 |

## 使用说明

### 1. 浏览和筛选信息

- 进入页面后，首页默认显示最新的寻物和招领信息。
- 点击“全部 / 招领 / 寻物 / 悬赏”可切换信息类型。
- 点击任意物品卡片进入详情页，查看时间、地点、特征和联系方式。

### 2. 搜索物品

- 点击首页搜索框，输入“校园卡”、“雨伞”、“图书馆”等关键词。
- 可使用热门搜索和搜索历史快速搜索。
- 点击相机按钮可选择或拍摄图片，系统会根据图片相似度和识别文字查找候选信息。

### 3. 发布寻物或招领

1. 点击底部中间的“发布”。
2. 选择“寻物启事”或“失物招领”。
3. 填写物品名称、分类、地点、时间和联系方式。
4. 可选择上传最多 3 张图片，或使用“拍照识物”自动填充物品分类。
5. 寻物信息可选择悬赏金额。
6. 点击“立即发布”，系统会自动与类型相反的信息匹配。

### 4. 查看匹配和联系对方

- 发布后如果存在匹配，成功弹窗会显示候选数量和最高匹配度。
- 在详情页中可查看“图片相似度”、“物品类别相同”等匹配依据。
- 点击“联系 TA”进入站内聊天；电话联系为原型演示效果，不会真正拨号。

### 5. 标记完成和感谢

- 进入底部“我的”，打开自己发布的信息。
- 失物找回或物品归还后，点击底部状态按钮标记完成。
- 完成后可继续写感谢信或查看感谢内容，并在“我的”页面查看爱心积分。

### 6. 其他入口

- “校园地图”可查看常见丢失地点并快速搜索该区域。
- “消息”显示联系提醒、匹配结果和系统消息。
- “我的”显示个人发布、状态统计、爱心积分和感谢信墙。

## 操作体验说明

当前原型的主流程较直观：底部导航始终可见，首页提供搜索、拍照和分类快捷入口，发布表单有必填验证，操作后会显示 Toast 或成功弹窗。首次使用的同学不需要了解代码即可完成浏览、搜索和发布。

需要注意的原型限制：

- 首次识图需要下载模型，可能比普通搜索慢。
- 桌面浏览器中“拍照”通常表现为选择本地图片；手机浏览器可直接调起摄像头。
- 为保证每次演示的数据环境干净，测试期间的发布、消息和状态变更不会持久保存。
- 图片相似度只是候选提示，最终仍需要根据挂件、划痕、卡号尾号等细节人工确认。

## 修改约定

1. 不要随意调整 HTML 底部的脚本顺序；后续模块会使用前置模块声明的全局数据和函数。
2. 演示数据只放在 `js/core/data.js`。
3. 匹配权重只在 `js/features/matching.js` 的 `MATCH_WEIGHTS` 中修改。
4. 新增样式放入对应的 CSS 子文件，不要将具体样式写回 `css/style.css`。
5. 每组用例或正式演示前，刷新页面即可恢复干净的初始数据。
