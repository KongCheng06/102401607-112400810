# 手工回归测试用例

每条用例前刷新页面，使用 Chrome/Edge 最新稳定版完成主流程，再用 Safari 或移动端浏览器做兼容回归。

## P0：启动与导航

1. 打开主页，首页卡片列表正常显示。
2. 依次进入“信息”、“发布”、“消息”和“我的”。
3. 从任意二级页返回，页面不白屏且返回层级正确。

预期：无 JavaScript 报错，所有页面可达。

## P0：发布校验

1. 直接点击“立即发布”，按字段顺序出现必填提示。
2. 选择“寻物启事”，填写名称、类别、地点、时间和联系方式。
3. 发布后返回首页，新条目应出现在列表顶部。

预期：发布期间按钮显示“正在分析并匹配…”，不会重复提交。

## P0：无图智能匹配

1. 发布“寻物启事”。
2. 名称填“黑色折叠伞”，类别选“水杯雨伞”。
3. 地点选“京元餐厅”，时间选“今天”，完成发布。

预期：显示“发布成功 · 发现匹配”，可查看“黑色折叠伞一把”。该用例用于验证缺图归一化逻辑。

## P0：以图比图

1. 准备同一物品的两张照片 A/B，角度可略有不同。
2. 先发布一条“失物招领”并上传 A。
3. 再发布类型相反的“寻物启事”并上传 B，其他字段保持接近。
4. 打开匹配详情。

预期：匹配依据中出现“图片相似度 xx%”；不同类物品的对照图得分应显著低于同一物品。

## P1：拍照搜物

1. 先发布一条带图片的信息。
2. 返回首页，点击搜索框右侧的相机。
3. 选择相同或相似图片。

预期：结果按综合得分排序；有可比图片的卡片显示“图片相似 xx%”。

## P1：识图降级

1. 加载页面后断开网络，或在浏览器开发者工具中阻止 TensorFlow/MobileNet CDN。
2. 执行上传图片和发布匹配。

预期：主流程不报错、不无限等待；15 秒内退回本地图像指纹。

## P1：状态与互动

- 详情页图片、发布人和联系方式正常。
- “我的”中可将条目标记完成。
- 完成后可写或查看感谢信，积分变化正确。
- 站内聊天可通过按钮或回车发送非空消息。
- 消息中心的可关联消息能打开对应详情。

## 结束条件

测试通过需同时满足：

- 浏览器控制台无未处理异常。
- P0 用例全部通过。
- 图片模型加载失败时，核心发布和搜索仍可用。
- 每条用例刷新后可重复得到同样的基线结果。
